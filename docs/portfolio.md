# PharmaQC — RAG-ассистент для контроля качества

## Краткое описание для портфолио

Разработал HTTP-сервис, который отвечает сотрудникам фармацевтического ОКК на вопросы по внутренним регламентам и показывает источники. Сервис поддерживает два контура: воспроизводимый локальный BM25 RAG без внешних ключей и генеративный RAG на ChromaDB + Groq с проверкой цитат, retry и контролируемыми ошибками.

В рамках дипломного проекта исправил потерю текста при структурном чанкинге, добавил мультизапросы для многошаговых вопросов, проверку наличия объекта в корпусе, явные оговорки для общих правил и обработку числовых допусков. На одном фиксированном наборе из 10 сценариев accuracy выросла с 0.50 до 1.00, Hit@k — с 0.889 до 1.000; результат подтверждён тремя прогонами каждой конфигурации.

Реализовал FastAPI endpoints `/api/v1/ask` и `/health`, конфигурацию через YAML и переменные окружения, обработку HTTP 422/500/502/503, логирование без текста вопросов, Dockerfile, 66 автотестов и автоматическую HTTP smoke-проверку. Сборка и запуск контейнера независимо проверены на Windows с Docker Desktop: контейнер `healthy`, 4/4 HTTP-сценария PASS. Подготовил документацию, сценарий демонстрации и презентацию.

**Стек:** Python, FastAPI, Pydantic, BM25, rank-bm25, ChromaDB, Sentence Transformers, Groq API, Docker, pytest.

**Ограничение:** результат относится к пяти учебным регламентам и десяти тестовым вопросам; перед производственным использованием нужны расширенная экспертная оценка и проверка на реальных документах.
