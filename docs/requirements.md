# Требования и способы проверки

Версия: 3.0.0. Основной проверяемый контур — `PHARMAQC_ENGINE=local`; требования, относящиеся только к внешней LLM, отмечены отдельно.

## 1. Функциональные требования

| ID | Требование | Способ проверки | Результат |
|---|---|---|---|
| FR-01 | Принимать вопрос на русском языке через HTTP | `POST /api/v1/ask`, штатный сценарий в `scripts/smoke_test.py` | PASS |
| FR-02 | Возвращать ответ только на основе корпуса | Автотесты local/Groq grounding; ручной разбор 10 ответов | PASS |
| FR-03 | Указывать документы-источники | Проверка `sources` в API и автотестах | PASS |
| FR-04 | Отказываться при отсутствии информации | Q7, `test_improved_refuses_unknown_object`, HTTP no_answer | PASS |
| FR-05 | Обрабатывать exact, multi_hop, partial и no_answer | 10 сценариев × 3 прогона baseline/improved | PASS |
| FR-06 | Для общего правила явно отмечать отсутствие отдельного указания | Q6, Q10; проверка `partial=true` и оговорки | PASS |
| FR-07 | Объединять несколько фрагментов для сложного вопроса | Q5 и Q9; проверка обязательных фактов | PASS |
| FR-08 | Предоставлять `/health` | HTTP smoke, `test_health_ready`, `test_health_not_ready` | PASS |
| FR-09 | Загружать конфигурацию без изменения кода | `test_config.py`, пресеты baseline/improved | PASS |
| FR-10 | Не переобучать и не перестраивать индекс при каждом запросе | Local: загрузка готового JSONL; Groq: загрузка сохранённой ChromaDB | PASS |

## 2. Требования к качеству

| ID | Критерий | Цель | Метод | Факт |
|---|---|---:|---|---:|
| QR-01 | Accuracy на фиксированном наборе | ≥ 0.80 | `scripts/evaluate.py`, 10 вопросов × 3 прогона | **1.00** |
| QR-02 | Hit@k по ожидаемым документам | ≥ 0.90 | Метаданные найденных чанков | **1.000** |
| QR-03 | Галлюцинации на наборе | 0 | Автоматические правила `judge` | **0** |
| QR-04 | Корректные отказы на no_answer | 1/1 | Q7 в каждом прогоне | **1/1** |
| QR-05 | Ложные отказы | 0 | exact/multi_hop в каждом прогоне | **0** |
| QR-06 | p95 локального in-process ответа | < 10 с | `time.perf_counter`, nearest-rank p95 | **≤ 1.2 мс** |
| QR-07 | Воспроизводимость | Одинаковая accuracy в 3 прогонах | Повторы одного пресета | **1.00 / 1.00 / 1.00** |

Показатели относятся к малому учебному набору и локальному движку. Они не являются SLA и не оценивают качество Groq-режима.

## 4. Критерии приёмки проекта

- Сервис запускается без ключа и дополнительных ручных шагов в local-режиме.
- Все 66 автотестов проходят.
- Четыре HTTP smoke-сценария завершаются со статусом PASS.
- Improved превосходит baseline по accuracy на том же наборе: 1.00 против 0.50.
- Отсутствуют реальные секреты в исходниках, документации и демонстрационных результатах.
- Подготовлены README, архитектура, отчёт, сценарий демонстрации, презентация и описание для портфолио.
